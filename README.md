# AI Stock Market Analysis & Prediction Platform

An end-to-end AI-powered stock analysis and decision support 
platform for the Indian stock market.

## Stocks Covered
- TVS Motor Company (TVSMOTOR.NS) — Automobile & EV
- Solar Industries India (SOLARINDS.NS) — Defence & Industrials
- HDFC Bank (HDFCBANK.NS) — Banking & Finance

## What This Project Does
- Collects 6+ years of historical NSE stock data
- Computes 27 technical indicators (RSI, MACD, Bollinger Bands etc.)
- Trains 3 ML models — Gradient Boosting, ARIMA, LSTM
- Generates BUY / HOLD / SELL signals with confidence scores
- Explains predictions using SHAP (Explainable AI)
- Displays everything on a live Streamlit dashboard

## Tech Stack
Python · Pandas · Scikit-learn · TensorFlow · 
Statsmodels · SHAP · Plotly · Streamlit
